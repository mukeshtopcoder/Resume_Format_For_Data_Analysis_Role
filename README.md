# RESUME CHECKLIST

Before submitting your resume:

- Keep the resume concise and relevant.
- Use a clean, professional layout.
- Put the most relevant skills near the top.
- Use keywords from the target job description where they truthfully match your experience.
- Quantify achievements whenever you have real numbers.
- Focus project descriptions on the problem, your work, and the resulting insight/outcome.
- Include GitHub or portfolio links for projects that recruiters can review.
- Check spelling, grammar, dates, and formatting.
- Use consistent job titles and date formats.
- Do not claim technologies or achievements you cannot explain in an interview.
- Do not include confidential company data in your portfolio.

---

# STRONG BULLET FORMAT

Avoid weak statements such as:

> Worked on Power BI dashboards.

Prefer a more specific statement:

> Developed Power BI dashboards to monitor sales, profitability, and regional KPIs using Power Query, DAX measures, and interactive drill-through analysis.

Even stronger when you have verified numbers:

> Automated a weekly sales reporting workflow using Power Query and Power BI, reducing manual preparation time from 4 hours to 45 minutes.

Use this structure:

**Action + What You Did + Tool/Method + Measurable Result**

Example:

> Analyzed 500K+ transaction records using SQL and Power BI to identify regional sales trends and reduce recurring manual reporting effort by 30%.

Only use numbers that you can support.
